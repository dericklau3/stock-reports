# AAPL｜最新财报三张表：面子、里子、底子

## 1. 利润表｜面子：最新一季度赚得怎么样？

苹果最新完整年度财报是 **FY2026 Form 10-K（2026-11-03 提交）**；利润表优先采用已正式披露的 **FY2026 Q4 单季度未经审计数据**，与 FY2025 Q4 同期比较。下表金额均为**亿美元**，每股收益除外。

| 项目 | FY2026 Q4（2026-06-28—09-26） | FY2025 Q4（2025-06-29—09-27） | 变化／怎么理解 |
|---|---:|---:|---|
| 产品收入 | 829.04 | 737.16 | +12.5%，手机、电脑等硬件收入 |
| 服务收入 | 315.73 | 287.50 | +9.8%，订阅、平台、合作等服务 |
| **营业收入合计** | **1,144.77** | **1,024.66** | **+11.7%，销售规模扩大** |
| 营业成本 | 596.57 | 541.25 | +10.2%，增幅低于收入 |
| **毛利润** | **548.20** | **483.41** | **+13.4%，销售收入扣除直接成本后剩余金额** |
| **毛利率** | **47.9%** | **47.2%** | +0.7 个百分点；本季关税退税约贡献 1 个百分点 |
| 研发费用 | 117.30 | 88.66 | **+32.3%**，增加明显 |
| 销售、一般及管理费用 | 74.59 | 70.48 | +5.8% |
| **营业利润** | **356.31** | **324.27** | **+9.9%，增幅低于收入** |
| 营业利润率 | 31.1% | 31.6% | 下降约 0.5 个百分点 |
| 税前利润 | 361.35 | 328.04 | +10.2% |
| **净利润** | **307.11** | **274.66** | **+11.8%，扣除税费后真正的会计利润** |
| 净利率 | 26.8% | 26.8% | 基本持平 |
| 稀释每股收益（美元/股） | **2.10** | **1.85** | **+13.5%，增幅也受到股份数量变化影响** |

**怎么看：** **面子变好**：最新一季收入和净利润均实现双位数增长，毛利率小幅改善。但研发费用增加 32.3%，使营业利润率略降；且官方明确指出关税退款给本季毛利率带来约 **1 个百分点**的有利影响，所以不能把毛利率上升全看作经营效率提升。净利润属于**这个季度**，不能直接拿来与第二张表的**全年**经营现金流相比。[来源：苹果向 SEC 提交的 FY2026 Q4 财务报表（未经审计）](https://www.sec.gov/Archives/edgar/data/320193/000032019326000024/a8-kex991q4202609262026.htm)；[FY2026 10-K（经审计年度数据）](https://www.sec.gov/Archives/edgar/data/320193/000032019326000026/aapl-20260926.htm)。

## 2. 现金流量表｜里子：利润有没有变成真钱？

FY2026 的 10-K 披露的是**全年现金流量表**，不是单独的第四季度。以下均为**亿美元**；负数代表该项消耗现金，部分正数代表增加现金。2026 财年为 **2025-09-28—2026-09-26**，对照的 2025 财年为 **2024-09-29—2025-09-27**。

| 项目 | FY2026 全年 | FY2025 全年 | 变化／怎么理解 |
|---|---:|---:|---|
| 全年净利润（现金流起点） | 1,321.75 | 1,120.10 | +18.0%，与利润表全年同口径 |
| 折旧和摊销加回 | +134.23 | +116.98 | 账面扣过但当期不再支付的现金费用 |
| 股权激励费用加回 | +137.89 | +128.63 | 非现金费用加回，**不是新增收款**，仍有股东经济成本 |
| 应收账款变动的现金影响 | -39.94 | -66.82 | 都占用现金，2026 年占用较少 |
| 存货变动的现金影响 | **-89.05** | +14.00 | **明显占用现金**，需关注库存积累 |
| 其他流动及非流动资产变动影响 | -211.17 | -91.97 | 该类资产相关占用增加 |
| 应付账款变动的现金影响 | +121.71 | +9.02 | 供应商应付款增加带来现金缓冲 |
| **经营活动现金流（CFO）** | **+1,450.97** | **+1,114.82** | **+30.2%，经营产生的现金增长快于净利润** |
| 购置固定资产现金支出（资本开支） | -90.41 | -127.15 | 现金投入减少；不代表全部供应链投入减少 |
| **简化自由现金流（CFO－资本开支）** | **+1,360.56** | **+987.67** | **+37.8%，经营现金扣除本公司固定资产购置支出后剩余** |
| **投资活动净现金流** | **-172.80** | +151.95 | 由流入转为流出；包含证券买卖及固定资产投资 |
| 回购股票支付现金 | -863.90 | -907.11 | 将现金返还股东，金额仍大 |
| 支付股息及股息等价物 | -157.21 | -154.21 | 小幅增加 |
| 偿还长期借款本金 | -123.96 | -109.32 | 还债现金支出增加 |
| **筹资活动净现金流** | **-1,274.46** | **-1,206.86** | 主要是回购、股息、还债等现金流出 |
| **全年现金及受限现金净变化** | **+3.71** | **+59.91** | 2026 年经营、投资、筹资三项合计 +3.71 |
| 期末现金及现金等价物 | 363.05 | 359.34 | 与第三张表对应；本期报表两种现金口径数值一致 |

**怎么看：** **里子较扎实**：FY2026 净利润约 **1,322 亿美元**，但经营实际产生约 **1,451 亿美元**现金，经营现金流约为净利润的 **1.10 倍**。要留意存货导致的 **89 亿美元现金占用**，以及股权激励费用加回不是顾客实际付款；不过，即使支付本公司的固定资产购置支出，简化自由现金流仍超过 **1,360 亿美元**。现金没有同比大增，主要因为公司继续大规模回购、分红和还债，而不是没有产生经营现金。[来源：苹果 FY2026 10-K 第 36 页，合并现金流量表](https://www.sec.gov/Archives/edgar/data/320193/000032019326000026/aapl-20260926.htm)。

## 3. 资产负债表｜底子：公司的家底够不够厚？

资产负债表是**期末某一天的余额**，不是一整季或全年的收入。以下金额为**亿美元**；比较的是 **2026-09-26** 和 **2025-09-27** 两个财年末，差额为余额变化而非同比销售增速。

| 项目 | 2026-09-26 | 2025-09-27 | 变化／怎么理解 |
|---|---:|---:|---|
| 现金及现金等价物 | **363.05** | **359.34** | +3.71，和现金流量表期末余额相符 |
| 流动有价证券 | 204.17 | 187.63 | +16.54，较短期内可变现的证券投资 |
| 非流动有价证券 | 802.13 | 777.23 | +24.90，并非全部等同于随时可用的活期现金 |
| **现金及有价证券合计（计算值）** | **1,369.35** | **1,324.20** | +45.15；包括非流动证券 |
| 应收账款 | 438.17 | 397.77 | +40.40，账面上尚待客户付回的款项 |
| 供应商非贸易应收款 | 398.96 | 331.80 | +67.16，需与现金流占用结合看 |
| **存货** | **145.41** | **57.18** | **+88.23，增长约 154%**，需要持续关注 |
| **流动资产合计** | **1,738.57** | **1,479.57** | +259.00 |
| 固定资产净值 | 520.84 | 498.34 | +22.50 |
| 无形资产净值 | 202.78 | 110.93 | +91.85；增幅较大，须观察后续价值与减值 |
| **总资产** | **4,045.48** | **3,592.41** | **+453.07，家底账面规模扩大** |
| 应付账款 | 822.52 | 698.60 | +123.92，对供应商的应付款增加 |
| **流动负债合计** | **1,699.15** | **1,656.31** | +42.84，一年内负担仍大 |
| **流动比率（计算值）** | **1.02 倍** | **0.89 倍** | 流动资产／流动负债；短期账面覆盖有所改善 |
| 短期票据及一年内到期债务 | 119.03 | 203.29 | -84.26，仅是有息借款的一部分 |
| 长期债务 | 682.08 | 783.28 | -101.20 |
| **有息借款合计（计算值）** | **801.11** | **986.57** | **-185.46**，不把全部应付账款也当借款 |
| **总负债** | **2,924.55** | **2,855.08** | +69.47，包括供应商款、各种经营负债及借款 |
| **股东权益** | **1,120.93** | **737.33** | +383.60；账面资产扣除负债后的剩余 |
| **现金与证券－有息借款（计算值）** | **+568.24** | **+337.63** | +230.61，**不是完全自由可用的净现金**，未扣除租赁及其他负债 |

**怎么看：** **底子整体较厚，短期营运资金不能掉以轻心**：苹果的现金加有价证券约 **1,369 亿美元**，高于上述有息借款约 **801 亿美元**；流动比率从 **0.89 升至 1.02**，但缓冲并不宽。最值得继续盯的是存货：期末金额同比较上个财年末增加 **154%**，这可能涉及备货，也可能影响周转，**光看余额不能直接认定滞销**。核对关系成立：**总资产 4,045.48＝总负债 2,924.55＋股东权益 1,120.93（亿美元）**；这一张表同时解释了为什么经营现金流很好，但现金余额没有明显增加。[来源：苹果 FY2026 10-K 第 34 页，合并资产负债表](https://www.sec.gov/Archives/edgar/data/320193/000032019326000026/aapl-20260926.htm)。
