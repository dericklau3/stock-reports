# Stock Reports Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a GitHub Pages-ready static website that lists stocks from `research/COMPANIES` and renders each company's tracker and deep research reports.

**Architecture:** Add an Astro app under `website/`. A Node script scans the existing Markdown research tree at build time and writes `src/data/report-index.json`; Astro pages consume that JSON for the index, stock detail, and report views.

**Tech Stack:** Astro, Node ESM scripts, Markdown rendered with `marked`, Node built-in test runner.

## Global Constraints

- Do not move or rewrite existing files under `research/COMPANIES`.
- Keep the site static so it can deploy on GitHub Pages.
- Use `website/` as the web app boundary.
- Preserve unrelated dirty files in the repository.
