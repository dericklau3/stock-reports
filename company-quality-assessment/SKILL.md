# 公司质量评估：写给第一次了解公司的读者

**任务不是填三张检查清单，而是让没学过财务和管理的人真正读懂：谁在带领公司、钱是怎么赚来的、这群人为什么能持续把事情做好。** 研究要严谨，呈现要像一位懂公司的朋友在认真讲解，不能像财报摘要、审计底稿、论文和术语百科。

## 一、读者体验：比形式完整更重要

1. **先说人话，再解释概念，再举这家公司的真实例子，最后给判断。** 例如不要直接说「CEO 资本配置能力相对稳健」，而要讲：「CEO 要决定赚钱后是研发、收购还是回购股票。决定对不对，不是看花了多少钱，而是看后来创造了什么。苹果把钱持续投向自研芯片，产品上的价值是……；但新任 CEO 的独立成绩还需时间观察。」
2. **像回答有趣的问题一样写标题。** 小标题优先写「苹果到底靠什么赚钱？」「为什么有人换手机还想买 iPhone？」「出现错误时，公司会不会改？」而不是「2.1 客户黏性：优势明显」「事实层级／风险因素／验证信号」等报告腔。专业词只在必要时括号解释一次，不能堆英文缩写。
3. **具体、可想象**：CEO 用真实的人和关键决策；商业模式用一个购买者从付款到公司收到钱、承担成本的路径；文化用可查的产品决策、纠错、用人、制度落实。读者能在脑中看到一件事怎样发生，而不是只看抽象形容词。
4. **少而关键**：每一章挑 2–4 个最能说明问题的事实或案例；数字只留支撑判断的少数关键数，并当场解释它说明什么。不要复制完整财务表、流程清单、长履历、来源名录或冗长法律程序。篇幅由论据决定，以阅读顺畅为准，不为凑字数添内容。
5. **平衡、不吹捧**：每章必须讲清一项有力证据、一个真实限制或反面案例以及因此如何判断。不能为了「有故事」发明公司内部对话、用户行为、CEO 个人动机或决策结果；举虚构场景时明确标「举例假设」，不能和事实混写。
6. **每段只讲一件事**：2–4 句话为宜；多写因果（因为 A → 所以 B → 但 C），少用「优势明显／待验证／反证」重复标签。每个 H2 开头一句话直给总体判断，之后用自然叙事展开。
7. **零基础读者检查**：没接触过 ROIC、FCF、SBC、ASP、毛利率的人能否读懂？需要用到专业概念就先解释，例如「毛利率 76%」应说「每收 100 元服务收入，扣除直接成本后大约剩 76 元，还没减全部研发和管理费用」，不要暗示那就是净利润。
8. **避免毫无信息量的句子**：不要用「未来仍面临挑战」「存在一定不确定性」填空。必须说清楚谁会挑战它、为什么、挑战成功后影响哪部分收入或经营；证据欠缺则直言「无法判断」，并说明缺什么关键资料。

## 二、内部研究要求（核验，但不在正文原样列检查表）

### CEO：他能不能做正确决定，还能带团队做成？

- **方向**：是否提前看见重要变化并做了相应的实际投资；事后检验，而非只听未来愿景。
- **花钱**：研发、收购、扩大产能、分红、回购各花了多少、理由是什么、有没有回报；区分企业整体历史表现与当任 CEO 的个人表现。
- **执行**：承诺的产品是否交付、能否让顾客实际使用或付款；别把宣布计划当成功。
- **长远思考**：是否愿意为未来竞争力承受合理的短期成本；不能单用研发规模证明聪明。
- **用人**：重要人才、组织授权、接班和激励是否有可核实表现。
- 必须核实**现任 CEO 姓名与上任时点**，准确区分现任与前任、产品负责人和其他高管的成果。刚上任的人不因公司历史成功就获得「优秀 CEO」评价。

### 商业模式：到底谁付款，公司凭什么把钱留下？

- **先讲真实收款链**：主要买家是谁、买什么、为什么花钱、公司如何收费、由谁承担主要成本。不同收入来源需分别说明，不把整个公司说成一种收费方式；尚未赚钱的业务不能写成已赚钱。
- **定价权**：为什么有的客户愿多付钱？有无同类价格、需求量和毛利证据？产品结构升级不等于涨价不掉量。
- **客户黏性**：为什么买过的人愿意再买、换平台有何成本？设备数量不等于独立客户数或留存率。
- **利润和现金**：营业收入、利润、经营现金、必要资本支出的关系；必要时解释毛利润不是净利润，经营现金流不等于可自由分配的钱；股权激励与股数变化会影响股东收益。
- **护城河**：竞争者为什么难以复制？技术、品牌、网络效应、成本、渠道还是用户迁移成本？并找一个能削弱护城河的真实竞争者、政策或技术趋势。
- 多业务公司既说明各业务是否已产生收入，也指出什么业务更赚钱；缺少分项利润披露时不能编造数字。

### 企业文化：它到底怎样做事，错误能否被发现并纠正？

- **对用户**：质量、安全、服务、长期信用是否影响真实产品决定。
- **专业与协作**：是让懂行的人做决定，还是过度依赖个人权威？只能根据可观察案例判断。
- **真实反馈**：员工能否提出不同意见，出了错有没有承认和纠正？制度宣称与实际做到必须分开；争议与监管指控不等于最终定罪。
- **创新与变通**：旧方法过时后敢不敢改，新技术有没有落地，而不只是开发布会。
- **人才与激励**：是否培养接班人、留住关键团队、奖励真正的长期成果，还是只激励短期股价。
- 产品做得好不必然等于企业文化处处好；匿名评论、公司宣传、个别事件都不足以推断全体员工的处境。

### 证据原则

- 先查当前公开财报、SEC/监管文件、公司公告、实际产品及客户数据；争议最好用监管原始资料并核对状态。关键事实只在其对应段落**就近给出原始来源链接**。
- 研究时内部确认披露日、事实发生日和数据期间，但**不要生成研究日期或资料口径元数据区**；必须注明期间的数字就在使用该数字的句子里标明期间。
- 区分事实、公司自述、推断、举例假设及尚未发生的情景，不为了故事性混淆它们。
- 公司类型不同可调整采用的案例和指标，不用制造公司不披露的数据。

## 三、最终报告的唯一结构

最终 Markdown **仅有一个 H1 标题 + 3 个 H2 章节**，可用少量有信息量的 H3 问题式标题。

```md
# AAPL｜苹果：CEO × 商业模式 × 企业文化

## 1. CEO｜掌舵的人是否值得信任？
[开场一句话给判断，解释 CEO 真正要做什么，再借 2–4 件公司的真实决定讲能力与局限；必要时归并五项能力，不机械把五条都列成标题]

## 2. 商业模式｜苹果到底怎样赚钱？
[以买东西／付服务费的生活场景讲收入链，再解释为什么客户愿付、愿留下、利润能否兑现及谁可能抢走生意；覆盖四项核心特征]

## 3. 企业文化｜为什么这家公司能持续做出产品？
[通过真实行为案例解释工作方式：质量、专业决策、敢不敢纠错、适应变化、人才和激励；不足之处也说清楚]
```

**禁止出现在最终报告的内容**：
- 标题后没有「公司信息 / 股票代码 / 研究时间 / 财务基准 / 研究边界」等信息列表；标题直接进入 CEO。
- 不要「公司质量总览」表、不做「五维能力表／四维特征表／风险台账」、不把每项拆成格式完全相同的「已核实／推断／反证／未来验证」四段。
- 不要额外章节：「最强反证与观察信号」「结语」「财务数据总览」「免责声明」「资料来源附录」「研究方法」「情景估值」等。关键反例和结论自然放在对应三个章节中。
- 不要长段落财报摘录、无解释的数据堆砌、空泛夸奖、满篇术语、同一句判断反复出现，也不要为讲解牺牲真实证据。
- 结果只评价长期公司质量，不直接从「好公司」推导出股票值得买、目标价或仓位建议。

**写作示例（演示方式，不是可以直接复用的事实结论）**：

> 「为什么用过苹果的人常常还买苹果？假设你已有 iPhone、AirPods 和 iCloud 照片库，换成别的品牌时，可能要重新安排照片、账号和设备联动。这是『客户黏性』：不是不许你换，而是换走需要付出时间。它能让苹果更容易留住客户，但我们仍要看真实留存数据，不能凭这个故事断言人人都会留下。」

示例里的用户经历为假设；研究其他公司必须换成该公司自己的实际赚钱方式与可核实案例。

## 四、交付前的阅读测试

- 读完 **CEO**，零基础读者能说出 CEO 是谁、他/她做过什么选择、哪些功劳属于前任、为何评价不能太高或太低吗？
- 读完 **商业模式**，读者能说出「谁付钱 → 买到了什么 → 公司承担什么成本 → 为什么还可能再付钱」吗？能区分收入、毛利、最终利润及现金吗？
- 读完 **企业文化**，读者能举出至少一项真实行为说明文化，并指出至少一个对文化宣传构成挑战的证据吗？
- 全文的证据和解释是否紧挨着？是否出现未经解释的缩写、表格堆砌、重复结论、独立元数据或无关章节？如有，重写。
- 三章必须各自有判断、讲得通的真实例子和有意义的限制；证据不足就直接写「不够资料判断」，不要虚构可信感。
