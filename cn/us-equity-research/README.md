# 美股投研 Skill

## 用途

这个 skill 用于帮助 Codex 对你已经选定的美股上市公司做深度投研和财报后追踪，并且默认用小白能懂的话解释公司业务如何运转、现在如何赚钱、未来可能如何赚钱。

默认逻辑是：只要输入股票代码或公司名，就做深度个股研究；如果问题提到财报、季报、指引、10-Q、股东信或业绩电话会，就做财报后追踪。其他形式的问题也应归入这两种模式之一；明确的窄问题只读取相关模块，不强制生成全篇。

无论公司业务看起来简单还是术语很多，都必须**先讲普通人能理解的真实交易过程**：这家公司具体做什么、解决客户什么问题、谁会买、客户为什么愿意付钱、卖的究竟是什么、钱怎么收以及扣掉哪些成本后才可能盈利。再给一个从客户需求到付费的短例子，之后才能进入专业分析；不允许用一堆缩写充当小白解释。

## 财务状况：让非专业读者看懂钱从哪里来、花到哪里去

完整报告财务章节不再用 `Financial Deep Dive` 开头，也不再默认展示多年 GAAP/TTM 大表、密集英文缩写及逐项核对长文。只写「**财务状况：收入、利润和现金**」，用一张简短的三列表格说明**关键指标、最新数值与期间、这说明什么**，通常 4–6 行，不强行凑数。

只保留最能判断公司的指标：收入与可比期间的增长、净利润或亏损、经营现金流、必要的设备/建设投入、投入后的现金变化、可用现金和主要债务（因行业选择取舍）。财年与半年不能当成同一期间直接比较；中文金额优先用容易理解的「亿美元/万美元」，附来源和必要时间范围。最后用 2–3 句话说明收入、盈利、资金状况及最大隐患。

**财务简化不等于不核实**：若利润主要来自一次性收益，或会计口径冲突影响结论，必须在相关指标附近用一句话说明，不能让读者误以为主营业务已赚钱。GAAP、TTM、OCF、FCF、SBC 等术语不要直接堆砌；关键原始财务数据、计算口径和更完整的财务核查放研究记录、估值依据或 `tracker.md`，只有真正改变结论的信息才进入正文。

## 公司正在做什么、做到哪一步

深度研究仍要覆盖公司重要经营进展，但**面向读者只展示三列、通常 3–5 行的简表**：「重点项目、为什么做与希望达到什么结果、当前进展与下一步」。每项必须讲清楚要解决什么客户/业务问题、对谁有用、希望带来什么收入或成本效果，不能只列项目名称；预期目标和已证实成果要分开。不再生成五列宽表，也不在表后逐项撰写 3.1、3.2 等大量重复内容。完整研究细节、项目时间表、原始承诺、证据、经济性和前后变化仍保留在 `tracker.md`；真正影响收入、利润或股价的材料放在财务、估值、风险章节。

尚未盈利不等于没有进展；宣布上线或合作也不等于商业化成功。使用不同产业的阶段门槛，不编完成百分比，不把没有新披露当没有工作。聊天摘要也必须包含重点事项的“正在做什么 / 最新进度 / 下一关”。

执行细则和验收清单：[Operating Agenda and Execution Progress](../../us-equity-research/references/operating-agenda-execution-progress.md)。

## 调用示例

```text
Analyze TICKER
Do a deep analysis of COMPANY
Analyze TICKER's latest earnings
Track COMPANY after earnings
分析 TICKER
深度分析 COMPANY
分析 TICKER 最新财报
追踪 COMPANY 财报后的变化
```

## 支持模式

- 深度个股研究：所有股票代码或公司名默认使用。
- 财报后追踪：用户提到 earnings、财报、季报、guidance、10-Q、股东信、投资者演示文稿、业绩电话会时使用。

## 输出要求

- 完整报告开头先给「投资观点、核心逻辑、主要风险」三项简短结论，用通俗中文说明。
- 使用最新且可引用的来源，不编造财务数据或估值假设。
- 会影响结论的关键数据要尽量做双源核验；如果来源冲突，要标出差异和置信度影响。
- 深度研究报告的估值分析中，应加入 forward P/E 快照表：当前 forward P/E、最近 1 年最高 forward P/E、最近 1 年最低 forward P/E，并写清日期、预测期间、会计口径和来源。只有历史数据覆盖与口径可比时才判断高/中/低位；季度样本不能冒充全年极值，不能用今日 EPS 回填历史股价。历史未取得与 P/E 不适用分别说明。
- 区分事实、假设、估算和观点。
- 必须包含风险、反证理由和 thesis 失效条件。
- 估值方法要匹配公司类型。
- 当估值是关键判断依据时，使用 bear / base / bull 三档情景。
- 关键数据不足时，使用 `Insufficient evidence`，不要强行给方向性观点。
- 核心输出开头仅保留三项摘要：「投资观点、核心逻辑、主要风险」，每项尽量用 1–2 句人话说明；不再单列 Confidence 或 Time horizon。**彻底禁止独立的 Executive View / Executive Summary / 执行摘要 / 先给结论章节（包括换名的同类总结）**，也不要在三项摘要后拼接大段价格分析、几条重要判断或历史更新。股价与估值放估值章节，最新业务进展放业务进度章节，历史变化放更新追踪章节；后文不重复三项结论。
- 所有公司 Business Model 必须先按「**做什么 → 解决什么问题 → 谁买、为什么买 → 卖什么、怎么收费 → 扣什么成本才能赚钱**」的顺序解释，再用一个简单交易实例串起来。确认过的真实客户才可举名；假设场景必须标明“举例假设”，不能把合作伙伴、渠道和最终使用者直接当作付费客户。多条核心业务要分别说明当前如何赚钱，未来规划不能冒充已经有的收入。
- 初学者部分禁止用专业词堆砌或先罗列缩写词典。无法回避的术语必须在首次出现时紧跟一句人话解释；芯片架构、财务指标、市场规模、竞争对比放在业务交易过程讲清楚之后。不要在 Business Model 章节里重复后续产品进展或估值的详细内容。
- 深度研究要加入巴菲特、芒格、段永平、李录四种投资风格视角，作为最终决策前的压测框架。
- 输出语言匹配用户语言：中文提问用中文，英文提问用英文。

## thesis 是什么意思

`thesis` 在这里可以理解为“投资逻辑”或“研究判断”。

例如：

- 为什么这家公司值得长期跟踪？
- 它未来增长主要靠什么？
- 市场可能低估了什么？
- 什么数据能证明这个判断是对的？
- 什么情况发生时，说明原来的判断错了？

所以 `thesis 失效` 的意思就是：原本支持这家公司投资逻辑的关键假设被证伪了。

## 研究结果怎么保存和查看

建议每家公司单独一个目录，把深度研究、财报追踪和当前状态分开保存：

```text
research/
└── COMPANIES/
    └── TICKER/
        ├── deep-research/
        │   ├── 2026-05-12-deep-research.md
        │   └── 2026-11-20-deep-research-v2.md
        ├── earnings-tracking/
        │   ├── 2026-Q2-earnings-tracking.md
        │   └── 2026-Q3-earnings-tracking.md
        └── tracker.md
```

### deep-research/

保存“完整深度研究底稿”，相当于某个时间点的完整投资逻辑快照。

一般不要频繁修改旧文件。公司逻辑发生大变化、需要重做一版完整研究时，再新增一篇，例如 `2026-11-20-deep-research-v2.md`。

### earnings-tracking/

每次财报后新增一篇追踪记录，用来回答：

- 本季度发生了什么？
- 指引有没有变化？
- 财务质量变好还是变差？
- 哪些假设被验证？
- 哪些假设被削弱？

### tracker.md

这是日常最该看的文件，记录这家公司当前最新状态。

建议 `tracker.md` 持续维护：

- 当前投资观点
- 当前核心逻辑
- 核心 thesis 假设
- 红线条件，也就是触发后必须重新审视或下调观点的信号
- 关键风险
- 最新财报后的变化
- 重点事项的最新证据、当前阶段、原始/修订时间表、下一关和瓶颈；保持事项名称，比较上次到现在的变化
- 管理层承诺、目标或战略里程碑的兑现情况
- 下次要重点跟踪的数据
- 什么情况会改变观点

## 更新规则

- 小变化：只更新 `tracker.md`，追加带日期的旧假设到新假设记录。
- 财报变化：新增 `earnings-tracking/...md`，再更新 `tracker.md`。
- 公司逻辑大变：新增一版 `deep-research/...-v2.md`，再更新 `tracker.md`。

平时主要看 `tracker.md`；需要追溯最初研究逻辑时，再看 `deep-research/`；需要看每次财报如何影响判断时，再看 `earnings-tracking/`。

## 管理层质量怎么跟踪

深度研究和财报后追踪都要检查管理层是否兑现过去说过的话，包括指引、产品节点、利润率目标、资本配置计划和战略承诺。

如果有财报电话会纪要，还要看管理层 Q&A 的回答质量：是否正面回答尖锐问题、是否给出具体数字、是否承认问题、是否和正式文件一致、是否只是用模糊的外部理由解释所有失误。

## 四位投资人视角

深度研究报告保留一个决策压测模块，引用前文证据并说明独特判断，避免重复：

- 巴菲特视角：商业模式、护城河、现金流、管理层、估值与安全边际。
- 芒格视角：商业质量、激励机制、长期复利能力、主要愚蠢风险。
- 段永平视角：用户价值、产品 / 品牌、企业文化、长期确定性。
- 李录视角：是否在能力圈、下行风险、安全边际、是否值得深度研究 / 高置信度配置。

最后要给一张综合评分表：商业模式、护城河、管理层、财务质量、估值吸引力、长期确定性、下行风险控制，每项用整数 `/10` 或证据不足时填 N/A，采用粗略锚点并说明理由，不平均成机械买卖评级。

这个模块可以回答“是否值得研究、在当前假设下是否看起来值得买入、是否适合长期持有、最大风险、需要继续跟踪什么”，但必须作为投研辅助，不应包装成个性化投资建议。

## 数据、估值与更新规则

- 关键数据记录数值、单位/币种、期间、口径、披露日和直接来源定位；两份转载不是独立核验，冲突不能取平均。
- 估值展示公式、企业价值到普通股/每股价值桥接、适用股数、价值时点、敏感性和计算复核；区分未来价格与今日内在价值，解释 SBC/融资如何处理。
- 财报追踪比较“上次假设 → 新事实 → 新预测 → 估值影响 → 观点变化”；共识需为财报发布前快照，首次覆盖建立基线。
- 外国发行人/ADR 核对币种、股份比例和申报口径；同业对齐估值日期与会计定义；重要增长变化与利润到现金差异分别解释。
- 置信度由关键证据及敏感性决定，不按篇幅或来源数量评分。
